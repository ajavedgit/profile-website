How this chatbot works

Four ideas · one small script

01

The system prompt

A hidden brief tells the AI who it is, what it knows (a short profile of me) and what it must not do. Changing this text changes the chatbot completely.

02

Conversation history

The AI has no memory. Every time you send a message, the page sends the whole conversation again so replies make sense.

03

The API call

The page sends one request to the Groq API with the key, the system prompt and the history. The reply comes back as text and is shown in the chat.

Use case

Why add this to a profile site?

Visitors rarely read a whole CV. A chatbot lets a recruiter or client ask a direct question — “Have you done mobile penetration testing?” — and get an instant, relevant answer, at any hour. The same pattern works for a shop’s FAQ, a course helper or a support desk.

Security note: in this demo the API key sits in browser code, which is fine on your own computer but not on a public site — anyone could copy it. For a real launch, put the key on a small server that forwards the requests and limits how often visitors can use it.
